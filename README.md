# Discovering Timișoara

This repository contains the static Discovering Timișoara website.

## Live site

https://sarmauazburatoare.github.io/hackatlon/

The site is deployed automatically to GitHub Pages when changes are pushed to `main`.

## Run locally

```bash
python -m http.server 4173
```

Open http://127.0.0.1:4173/ in a browser.
