# Timișoara, cameră cu cameră — local delivery

The final supplied prompt is the specification (copied to docs/prompt-final.md). The current user instruction replaces public publication with local deployment and shareable archives.

Build a static Vite/TypeScript application. Semantic DOM screens use fragment routes and a single catalog, with Three.js loaded only for museum scenes. Nine categories contain exactly 85 appearances / 84 entities. Romanian is default; ro/en/it/fr/es/zh-Hans are available. No API key, runtime CDN, account, analytics or recurring service.

Entrypoint follows the three-page PDF: painterly warm grey/cream, dove, white two-register mark, oval controls, language between controls on desktop and below on mobile. Original fonts/photographs require explicit licenses. An original replacement background and libre typography are permitted with documented deviations.

Shared recommendations filter verified open venues by confirmed minor access (default on), choose the closest eligible venue per entity, deduplicate, limit globally to five/ten with an origin, avoid immediate repeats and map one result to the same wheel angle in both modes. Unknown editorial facts are never promoted to verified facts.

Museum is actual WebGL geometry: roofless orthographic nine-room plan, reception, seating, Bega curve, 3D wheel and stylized heritage objects; direct room selection. Rooms have movement, look controls, collision and photograph-only frames. DOM alternatives provide keyboard access and WebGL fallback. Local map supports explicit origin confirmation; visitor origin remains in session memory.

Deliver production dist, source/lockfile, double-click launchers, local HTTP URL, compact build zip, complete source zip, and a truthful acceptance/content report outside dist. All app assets are local. Links to external operators require internet. Missing photos use neutral frames, missing recordings preserve written stories. Do not claim unperformed real-device, native-speaker or observational tests.

Implementation choices made by Codex: plain TypeScript DOM rather than React; procedural geometry rather than imported unlicensed models; session-only location; Python/Node launchers; no online publication this phase.
