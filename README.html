Pornire în trei pași

  1. Extrage întreaga arhivă ZIP într-un folder. Păstrează folderul dist și fișierele de pornire împreună.
  2. Pe Mac, deschide PORNESTE.command. Pe Windows, deschide PORNESTE.bat. Este necesar Python 3 sau Node.js, instalat pe calculator.
  3. Se deschide browserul, de regulă la http://localhost:8000/. Dacă portul este ocupat, folosește adresa afișată în fereastra serverului. Lasă această fereastră deschisă; Ctrl+C oprește serverul.

Pornire manuală

Din folderul extras, folosește una dintre comenzile:

python3 serve.py

Pe Windows: py -3 serve.py. Alternativa cu Node.js:

node serve.mjs

Aplicația are nevoie de server HTTP local. Nu deschide direct dist/index.html prin file://.

Cum partajezi

Trimite Timisoara-local-v0.3.zip prin email, Drive, OneDrive sau alt serviciu. Pentru codul editabil, teste și rapoarte există arhiva Timisoara-surse-v0.3.zip. Destinatarul extrage arhiva și urmează pașii de mai sus.

Nu există încă un site public. Adresa localhost funcționează doar pe calculatorul care rulează serverul. ZIP-ul nu rulează direct pe telefon; pentru acces obișnuit pe mobil este necesară o publicare ulterioară pe un serviciu de hosting.

Povești cu audio local

Sunt incluse 42 de MP3-uri: 7 povești în română, engleză, italiană, franceză, spaniolă și chineză simplificată, aproximativ 13 min 41 s în total.

Redarea pornește numai prin Play. Sunetul este inițial pe mut; primul Play îl activează dacă nu ai ales explicit să îl păstrezi mut. Poți modifica oricând controlul de sunet. La schimbarea limbii, povestea continuă din pasajul corespunzător, iar propoziția curentă este evidențiată. Textul și audio sunt disponibile offline.

Toate fișierele au trecut decodarea tehnică. Pentru 33 de clipuri distincte s-a verificat automat limba prin transcriere; traducerea și pronunția nu au validare de vorbitori nativi.

Ce funcționează fără internet

Interfața, catalogul, fotografiile incluse, muzeul compatibil WebGL, harta și indexul local, roțile și poveștile sunt servite de pe calculator. Linkurile către operatori și traseele externe necesită internet. Refuzul localizării GPS lasă disponibilă alegerea manuală a punctului de plecare.

Pentru dezvoltare

Arhiva cu surse include codul, lockfile, testele și rapoartele. Cu Node.js 22 sau mai nou:

npm ci
npm test
npm run build
npx playwright install chromium firefox webkit
npm run test:e2e
npm run dev

Testele în browser folosesc buildul dist, pe portul 4174. Pentru rezultate și numărul verificărilor finale, vezi docs/verification.md în arhiva cu surse.
